# Sprint 7: Тестовый проект для API Яндекс.Самокат

**О проекте**

Проект содержит автоматизированные тесты для API сервиса Яндекс.Самокат. Тесты проверяют основные функциональности: создание курьеров, авторизацию, создание заказов и получение списка заказов.

**Технологии**

| Компонент   | Версия | Назначение |
|-------------|--------|-----------|
| Java        |  11      |   Основной язык программирования   |
| Maven       |  3.9.0      |  Сборка и управление зависимостями    |
| RestAssured |  5.3.0      |    Фреймворк для тестирования  |
| Allure      |  2.24.0      |   Генерация отчетов о тестировании   |
| Jackson     |   2.15.2     |   Работа с JSON        |
| SLF4J       |   2.0.9     |  Логирование    |
| AspectJ     |   1.9.19     |  Для работы аннотаций @Step в Allure    |
